## Proceso para proponer un nuevo componente

**1. Verifica que no existe**

Revisa la lista de componentes y el backlog antes de proponer uno nuevo. Puede que ya esté en desarrollo.

**2. Abre un issue en GitHub**

Incluye:
- Nombre del componente
- ¿En qué proyecto se necesita?
- ¿Cuántas veces se reutilizaría?
- Referencia visual (captura, link a Figma, o ejemplo de otro DS)

**3. Diseño en Figma**

El equipo de diseño crea el componente en Figma con todas sus variantes y estados antes de que desarrollo empiece.

**4. Implementación**

Desarrollo implementa el componente siguiendo los estándares del DS.

**5. Review y merge**

PR con checklist completo → review → merge → publicación.

## Añadir un ícono

Los íconos no se generan con SVGR: el SVG se guarda en `packages/ui/src/icons/svg/` y se copia a un wrapper React.

1. Exporta de Figma un SVG **24×24** (un `<svg>` raíz, `viewBox="0 0 24 24"`, `currentColor`, sin hex).
2. Guárdalo como `packages/ui/src/icons/svg/nombre.svg`.
3. Copia `packages/ui/src/icons/_template-icon.tsx` → `nombre-icon.tsx`, pega los `<path>` y cambia el `displayName`.
4. Reexporta en `packages/ui/src/icons/index.ts`.
5. Verifica en Storybook: **Foundations / Icons**.

Detalle del contrato: `packages/ui/src/icons/svg/README.md`.
