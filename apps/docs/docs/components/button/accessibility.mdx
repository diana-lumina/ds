## HTML semántico

Usa el elemento `<button>` nativo — no `<div>` ni `<span>`. Esto garantiza comportamiento correcto de teclado y screen readers sin configuración adicional.

## Screen readers

El texto dentro del botón es leído automáticamente. Para botones de solo ícono, usa el componente `IconButton` con `aria-label` obligatorio:

```tsx
// ✅ correcto
<IconButton icon={<TrashIcon />} aria-label="Eliminar elemento" />

// ❌ incorrecto — botón sin nombre accesible
<Button leftIcon={<TrashIcon />} />
```

---

## Estado disabled

```tsx
// ✅ correcto — usa el atributo nativo
<Button disabled label="No disponible" />
```

El atributo `disabled` nativo excluye el botón del orden de tabulación y previene eventos de click automáticamente.
