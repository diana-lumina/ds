## Descripción

El Button se usa para acciones que el usuario puede ejecutar. La variante comunica la jerarquía e importancia de la acción dentro de una pantalla.

## Usage guidelines

**✅ Úsalo cuando:**
- El usuario necesita ejecutar una acción
- Hay una acción principal clara en la pantalla
- Necesitas comunicar jerarquía entre varias acciones

**❌ No lo uses cuando:**
- El destino es una URL externa o interna — usa `Link` en su lugar
- La acción es navegación entre secciones de la app

---

## Comportamiento

- En mobile mantiene el mismo tamaño que en desktop
- Con texto muy largo el botón crece horizontalmente — evita textos de más de 4 palabras
- El estado `disabled` bloquea clicks y reduce la opacidad al 50%
- Los íconos dentro del botón heredan el color del texto automáticamente

---

## Componentes relacionados

Usa **IconButton** cuando el botón solo contiene un ícono. Usa **Link** cuando la acción es navegación.
