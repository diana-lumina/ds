## Instalación

```bash
pnpm add @tec-ds/ui
```

---

## Uso básico

```tsx
import { Button } from "@tec-ds/ui"

<Button label="Guardar cambios" />
```

---

## Hierarchy

```tsx
<Button hierarchy="primary" label="Principal" />
<Button hierarchy="secondary" label="Secundario" />
<Button hierarchy="tertiary" label="Terciario" />
<Button hierarchy="destructive" label="Eliminar" />
```

---

## Con íconos

```tsx
import { PlusIcon, ArrowRightIcon } from '@workspace/ui/icons'

<Button leftIcon={<PlusIcon />} label="Agregar" />

<Button rightIcon={<ArrowRightIcon />} label="Siguiente" />
```

---

## Tone inverse

`tone="inverse"` aplica a `primary` y `secondary` (sobre superficies oscuras).

```tsx
<Button hierarchy="primary" tone="inverse" label="Primary" />
<Button hierarchy="secondary" tone="inverse" label="Secondary" />
```
