# Design System

Sistema de componentes para proyectos derivados de Tec360.

:::caution
Los componentes, tokens de color y marca están en desarrollo activo. Esta documentación evoluciona junto con el sistema.
:::

## ¿Qué es esto?

Una librería de componentes React que permite a los equipos construir interfaces consistentes sin partir desde cero. Está construida sobre Tailwind CSS v4, Radix UI y shadcn/ui.

## Stack técnico

- **React 19** + **Next.js 15**
- **Tailwind CSS v4**
- **Radix UI** + **shadcn/ui**
- **CVA** para variantes
- **Lucide React** para íconos
- **Storybook** para desarrollo y testing visual
- **Chromatic** para visual regression testing
