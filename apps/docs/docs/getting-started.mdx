## Instalación

```bash
pnpm add @tec-ds/ui
```

---

## Configuración

**1. Importa los estilos globales en tu layout raíz:**

```tsx title="app/layout.tsx"
import "@tec-ds/ui/globals.css"

export default function RootLayout({
  children,
}: {
  children: React.ReactNode
}) {
  return (
    <html lang="es">
      <body>{children}</body>
    </html>
  )
}
```

**2. Configura Tailwind para escanear los componentes del DS:**

```ts title="tailwind.config.ts"
export default {
  content: [
    './src/**/*.{ts,tsx}',
    './node_modules/@tec-ds/ui/dist/**/*.{js,mjs}',
  ],
}
```

---

## Primer componente

```tsx
import { Button } from "@tec-ds/ui"

export default function Page() {
  return (
    <Button label="Hola desde el Design System" />
  )
}
```
