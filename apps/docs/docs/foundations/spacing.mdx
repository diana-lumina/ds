# Spacing

Escala de espaciado base del Design System. Todos los valores derivan de una unidad base de `0.25rem` (4px).

:::caution
La escala de espaciado está pendiente de validación con el equipo de diseño.
:::

## Uso

Los tokens de espaciado se consumen a través de las utilidades de Tailwind:

```tsx
// padding
<div className="p-4">...</div>   // --space-4 → 1rem

// margin
<div className="mt-2">...</div>  // --space-2 → 0.5rem

// gap
<div className="flex gap-3">...</div>  // --space-3 → 0.75rem
```
