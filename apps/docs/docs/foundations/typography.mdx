# Typography

La fuente base del sistema es **Inter**. Todos los proyectos consumidores deben cargarla
antes de importar los tokens.

:::info 
Carga Inter en tu proyecto antes de usar los tokens tipográficos.
Pesos requeridos: `400`, `500`, `700`.

```html
<!-- Google Fonts -->
<link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;500;700&display=swap" rel="stylesheet">
```
:::

## Tokens CSS

Los tokens viven en `packages/tokens/src/typography.css` y se ajustan
automáticamente según el breakpoint.

```css
/* Uso en componente */
font-size: var(--ds-font-size-body-regular);
line-height: var(--ds-line-height-body-regular);
font-family: var(--ds-font-family-base);
```
