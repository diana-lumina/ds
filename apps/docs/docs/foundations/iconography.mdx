#  Iconography

El Design System usa **Lucide React** como librería de íconos. Lucide es open source, tiene más de 1,000 íconos y está optimizado para React con soporte de TypeScript.

---

## Instalación

Lucide React viene incluido como dependencia del DS, no necesitas instalarlo por separado.

Si lo necesitas directamente en tu proyecto:

```bash
pnpm add lucide-react
```

---

## Uso básico

```tsx
import { SearchIcon, BellIcon, UserIcon } from 'lucide-react'

export default function Example() {
  return (
    <div>
      <SearchIcon size={16} />
      <BellIcon size={20} />
      <UserIcon size={24} />
    </div>
  )
}
```

## Accesibilidad

```tsx
// ícono decorativo — oculto para screen readers
<SearchIcon size={16} aria-hidden="true" />

// ícono con significado — necesita label
<button aria-label="Buscar">
  <SearchIcon size={16} aria-hidden="true" />
</button>
```

:::tip
Siempre usa `aria-hidden="true"` en íconos decorativos y `aria-label` en el elemento padre cuando el ícono sea el único contenido del botón.
:::
