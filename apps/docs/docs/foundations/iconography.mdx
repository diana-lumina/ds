# Iconography

Los íconos del Design System viven en `@workspace/ui/icons`. Se pasan a los componentes como `ReactNode` (`icon`, `leftIcon`, `rightIcon`); el **tamaño lo define el componente** vía CSS sobre el `<svg>`.

---

## Uso en apps

```tsx
import { FloppyDiskIcon } from '@workspace/ui/icons'
import { Button, IconButton } from '@workspace/ui'

<Button leftIcon={<FloppyDiskIcon />} label="Guardar" />
<IconButton icon={<FloppyDiskIcon />} aria-label="Guardar" />
<FloppyDiskIcon size={24} />
```

Standalone, `size` acepta número o string (`24`, `"1em"`, `var(--icon-size-24)`). Default: `24`.

El color es **`currentColor`**: hereda el `color` del padre (o el token de ícono del componente).

---

## Tamaños (tokens)

| Token | px | Uso |
| --- | --- | --- |
| `--icon-size-16` | 16 | Compacto / inline |
| `--icon-size-20` | 20 | Controles (botones, chips, fields) |
| `--icon-size-24` | 24 | Default de interfaz |
| `--icon-size-32` | 32 | Destacado |

Stroke: `--icon-stroke-150` (1.5 px, íconos 16–20) y `--icon-stroke-200` (2 px, 24–32).

---

## Accesibilidad

Los íconos del catálogo son **decorativos** (`aria-hidden`). El nombre accesible va en el control:

```tsx
<IconButton icon={<FloppyDiskIcon />} aria-label="Guardar" />
```

Si el ícono se usa solo y debe anunciarse, pasa `title`.

---

## Añadir un ícono

1. Exporta SVG **24×24** desde Figma (ver contrato en `packages/ui/src/icons/svg/README.md`).
2. Guárdalo en `packages/ui/src/icons/svg/nombre.svg`.
3. Copia `packages/ui/src/icons/_template-icon.tsx` → `nombre-icon.tsx` y pega los `<path>`.
4. Reexporta en `packages/ui/src/icons/index.ts`.

Contrato mínimo del SVG: un `<svg>` raíz, `viewBox="0 0 24 24"`, `fill="none"`, paths con `currentColor` (nunca hex).
