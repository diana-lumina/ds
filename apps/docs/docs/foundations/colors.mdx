# Color

Sistema de color del Design System basado en tres capas: primitivos, semánticos y por componente.

:::caution
Los valores de color actuales son placeholders. La paleta final se definirá con el equipo de diseño.
:::

## Arquitectura de tokens

Los **primitivos** son valores raw con nombre de marca. Los **semánticos** asignan roles a esos valores. Los **componentes** consumen los semánticos.
