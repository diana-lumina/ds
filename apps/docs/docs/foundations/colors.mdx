# Color

Sistema de color del Design System en tres capas: **primitivos**, **semánticos** y **por componente**. Los componentes consumen semánticos (`--color-surface-*`, `--color-text-*`, `--color-border-*`, `--color-icon-*`, `--color-focus-*`). Los primitivos (`--color-neutral-*`, `--color-blue-*`) son referencia; no se usan directo en UI.

Los valores se resuelven por marca (`data-brand`). Cambia TEC 360 y TEC Educación Continua para comparar.
